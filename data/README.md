# data/

Local data files. Everything here except this README is gitignored.

Record where each dataset came from (URL, version, date fetched) below so it can be re-obtained.

**Coordinates:** all meshes and point files share one **pixel** coordinate
frame. Convert to µm with **0.005 µm per pixel** (5 nm SBEM pixels), e.g.
`load_mesh(path, scale=0.005)`.

| File / folder | Source | Notes |
|---|---|---|
| `cell.obj` | Provided by the user (2026-10). Byte-identical to `cell_wrapped_simplified_1cc.obj` in neuromesh-cgal | Whole space-specific neuron surface (SBEM, barn owl ICx), soma and spines as one connected surface. 164,911 vertices, 330,326 faces, watertight. About 62 × 56 × 45 µm. **Its spines were traced separately from the `TS*.obj` meshes**, so the two versions of each spine differ |
| `TS1.obj` … `TS76.obj` (9 files: TS1, 2, 3, 4, 21, 24, 48, 67, 76) | Provided by the user; the same 9 spines as the MASCAF repo (`jmrfox/mascaf`, `data/mesh/processed`) | Separately processed toric-spine surfaces, all watertight. From 2k faces (TS2) to 561k faces (TS4). Median edge 0.015–0.16 µm. Extents 2.3–11.5 µm |
| `TS*_AZ.txt` (TS1, 2, 3, 4, 48, 67, 76; **none for TS21, TS24**) | Provided by the user (2026-09) | **Active zones = synapse (PSD) locations**, one `x y z` per line, in pixels. Counts: TS1 25, TS2 6, TS3 46, TS4 23, TS48 18, TS67 8, TS76 5. The points lie 0.03–0.16 µm from the spine surface (presynaptic side), so snap them onto the membrane. No PSD areas are given |
| `TS*_neckpoint.txt` (all 9) | Provided by the user (2026-09) | Spine neck point(s), where the spine joins its parent, in pixels. **Some spines have several necks**: TS3 has 3 and TS21 has 2, all others 1. The points lie on the spine surface, 0.1–0.45 µm from `cell.obj` (the spine meshes were cut from the cell) |
| `TS1_syn_axon_dist.txt` | Provided by the user | TS1 AZ indices (1–25, presumably the row order of `TS1_AZ.txt`) grouped by presynaptic axon, one axon per line: 10 axons with 8, 4, 1, 4, 2, 1, 1, 2, 1, 1 synapses |
| `neuromesh/` | Copied 2026-10-23 from the user's local `neuromesh-cgal` (github.com/jmrfox/neuromesh-cgal, commit ec99312), `data/output/` | Segmentation of `cell.obj` (byte-identical to `cell_wrapped_simplified_1cc.obj`). Contains: `*_segmented.obj` (the mesh in sidecar face order), `*_segmented.seg` (segment ID per face), `*.sdf` (SDF per face), the merge log, and `parts/segment_NNN.obj`, 91 watertight parts with capped cuts (segment 2 = soma). Pixel units |
| `torus_dc.vtu` | Generated by `notebooks/01_fem_reference.py` | Demo output; safe to delete |
